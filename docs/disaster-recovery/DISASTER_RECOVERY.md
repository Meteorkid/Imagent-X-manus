# 🆘 灾备和恢复指南

## 📋 概述

本指南提供 ImagentX 项目的灾备和恢复策略。

## 🎯 灾备目标

### 1. RTO (恢复时间目标)
- **关键系统**: < 15 分钟
- **重要系统**: < 1 小时
- **一般系统**: < 4 小时

### 2. RPO (恢复点目标)
- **关键数据**: < 5 分钟
- **重要数据**: < 1 小时
- **一般数据**: < 24 小时

### 3. 可用性
- **年度可用性**: 99.9%
- **月度可用性**: 99.95%
- **计划维护**: < 1 小时/月

## 📊 灾备策略

### 1. 本地备份
**频率**: 每日
**保留**: 30 天
**内容**: 数据库、配置文件、用户数据

### 2. 异地备份
**频率**: 每周
**保留**: 90 天
**内容**: 完整系统备份

### 3. 实时复制
**方式**: 数据库主从复制
**延迟**: < 1 秒
**目标**: 实时故障切换

## 🔧 备份策略

### 1. 数据库备份
```bash
# 完整备份
pg_dump -h localhost -U imagentx_user imagentx > backup_$(date +%Y%m%d).sql

# 增量备份
pg_basebackup -h localhost -U replicator -D /backup/base -Ft -z -P
```

### 2. 配置文件备份
```bash
# 备份配置文件
tar -czf config_backup_$(date +%Y%m%d).tar.gz /etc/imagentx/

# 备份环境变量
cp .env .env.backup.$(date +%Y%m%d)
```

### 3. 用户数据备份
```bash
# 备份用户上传文件
rsync -avz /data/uploads/ /backup/uploads/

# 备份日志文件
rsync -avz /var/log/imagentx/ /backup/logs/
```

## 🚀 恢复流程

### 1. 数据库恢复
```bash
# 恢复完整备份
psql -h localhost -U imagentx_user imagentx < backup_20240101.sql

# 恢复增量备份
pg_restore -h localhost -U imagentx_user -d imagentx backup.tar
```

### 2. 配置恢复
```bash
# 恢复配置文件
tar -xzf config_backup_20240101.tar.gz -C /

# 恢复环境变量
cp .env.backup.20240101 .env
```

### 3. 用户数据恢复
```bash
# 恢复用户上传文件
rsync -avz /backup/uploads/ /data/uploads/

# 恢复日志文件
rsync -avz /backup/logs/ /var/log/imagentx/
```

## 🔔 故障切换

### 1. 自动切换
**触发条件**: 主数据库不可用
**切换时间**: < 30 秒
**验证**: 自动健康检查

### 2. 手动切换
**触发条件**: 计划维护或手动触发
**切换时间**: < 5 分钟
**验证**: 人工确认

### 3. 切换流程
1. 检测故障
2. 停止写入
3. 数据同步
4. 切换主从
5. 更新配置
6. 验证服务
