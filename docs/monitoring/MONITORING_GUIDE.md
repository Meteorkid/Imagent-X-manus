# 📊 监控和告警指南

## 📋 概述

本指南提供 ImagentX 项目的监控和告警策略。

## 🎯 监控目标

### 1. 可用性
- 系统可用性 > 99.9%
- 故障恢复时间 < 5 分钟
- 计划维护时间 < 1 小时/月

### 2. 性能
- API 响应时间 < 200ms
- 页面加载时间 < 2s
- 数据库查询时间 < 100ms

### 3. 资源
- CPU 使用率 < 70%
- 内存使用率 < 80%
- 磁盘使用率 < 80%

## 📈 监控指标

### 1. 应用指标
- **请求量**: 每秒请求数 (QPS)
- **响应时间**: 平均响应时间、P95、P99
- **错误率**: 5xx 错误率、4xx 错误率
- **并发数**: 并发连接数

### 2. 系统指标
- **CPU**: 使用率、负载
- **内存**: 使用率、交换空间
- **磁盘**: 使用率、I/O
- **网络**: 流量、连接数

### 3. 业务指标
- **用户**: 活跃用户数、注册用户数
- **对话**: 对话数量、对话时长
- **智能体**: 智能体数量、使用频率

## 🛠️ 监控工具

### 1. Prometheus
**用途**: 指标收集和存储

**配置**:
```yaml
# prometheus.yml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'imagentx'
    static_configs:
      - targets: ['localhost:8080']
```

### 2. Grafana
**用途**: 指标可视化和仪表盘

**仪表盘**:
- 系统概览仪表盘
- API 性能仪表盘
- 数据库性能仪表盘
- 业务指标仪表盘

### 3. Alertmanager
**用途**: 告警管理和通知

**配置**:
```yaml
# alertmanager.yml
global:
  resolve_timeout: 5m

route:
  group_by: ['alertname']
  group_wait: 10s
  group_interval: 10s
  repeat_interval: 1h
  receiver: 'web.hook'

receivers:
  - name: 'web.hook'
    webhook_configs:
      - url: 'http://localhost:5001/'
```

## 🔔 告警规则

### 1. 严重告警
- **系统宕机**: 服务无法访问
- **数据库故障**: 数据库连接失败
- **内存溢出**: 内存使用率 > 95%

### 2. 警告告警
- **高 CPU 使用率**: CPU 使用率 > 80%
- **高内存使用率**: 内存使用率 > 85%
- **高错误率**: 5xx 错误率 > 1%

### 3. 信息告警
- **部署通知**: 新版本部署成功
- **备份完成**: 数据库备份完成
- **证书过期**: SSL 证书即将过期

### 2. API 性能仪表盘

### 3. 数据库性能仪表盘

### 4. 业务指标仪表盘
- 用户活跃度
- 对话数量

## 🔧 监控配置

### 1. 应用监控
```java
// Spring Boot Actuator
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics,prometheus
  endpoint:
    health:
      show-details: always
```

### 2. 数据库监控
```yaml
# PostgreSQL 监控
spring:
  datasource:
    hikari:
      register-mbeans: true
```

### 3. 缓存监控
```yaml
# Redis 监控
spring:
  redis:
    timeout: 5000
```

## 📈 监控最佳实践

### 1. 监控原则
- **全面性**: 覆盖所有关键组件
- **及时性**: 快速发现和响应问题
- **准确性**: 确保监控数据准确

### 2. 告警原则
- **可操作性**: 告警必须可操作
- **优先级**: 区分告警优先级
- **去重**: 避免重复告警

### 3. 响应原则
- **快速响应**: 及时响应告警
- **问题定位**: 快速定位问题
- **恢复措施**: 采取恢复措施
