# Imagent X 风险台账（2026-04-07）

## 高风险
1. 敏感信息治理
- 现象：配置中出现默认 token/key。
- 影响：泄漏风险、审计风险、合规风险。
- 优先级：P0
- 建议：改为环境变量必填；仓库仅保留示例值。
- 回归点：本地/测试/生产三环境启动验证。

2. 构建产物入库噪音
- 现象：`apps/frontend/.next` 变更量大。
- 影响：PR 噪音、冲突上升、回滚困难。
- 优先级：P0
- 建议：完善忽略规则并清理索引。
- 回归点：`git status` 不再出现 `.next` 产物。

## 中风险
1. 前端 Provider 重复包裹
- 影响：重复初始化、潜在副作用重复触发。
- 优先级：P0
- 建议：全局 Provider 仅保留在根布局。
- 回归点：登录、主站、管理后台路径 smoke test。

2. 响应式断点体系分裂
- 影响：CSS 与 JS 判定不一致，出现布局跳变。
- 优先级：P0
- 建议：统一断点来源（Tailwind + JS 同源常量）。
- 回归点：移动端/平板/桌面断点切换测试。

3. Tailwind 动态类
- 影响：生产构建中样式丢失风险。
- 优先级：P0
- 建议：改为静态枚举映射。
- 回归点：`build` 后组件样式完整性。

4. 文档入口分散
- 影响：维护成本高、信息漂移。
- 优先级：P1
- 建议：根 README 作为索引，过程文档迁入 `docs`。
- 回归点：关键链接可达率检查。

## 低风险
1. 管理后台与主站样式差异
- 影响：视觉一致性不足。
- 优先级：P1
- 建议：收敛到统一语义 token 与容器规范。
- 回归点：主路径 UI 基线截图比对。
