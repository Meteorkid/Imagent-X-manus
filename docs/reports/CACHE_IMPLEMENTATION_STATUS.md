## 🔧 技术架构

### 缓存服务架构
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   ImagentX     │    │     Redis      │    │   Redis        │
│   Application  │◄──►│   Cache        │◄──►│   Commander    │
│                │    │   (6379)       │    │   (8081)       │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 缓存策略层级
```
L1: 应用层缓存 (Spring Cache)
    ├── 用户会话缓存
    ├── API响应缓存
    └── 计算结果缓存

L2: Redis分布式缓存
    ├── 会话存储
    ├── 数据缓存
    └── 消息队列

L3: 数据库持久化
    ├── PostgreSQL
    └── 文件存储
```
