# 📚 团队培训指南

## 📋 概述

本指南帮助新团队成员快速上手 ImagentX 项目开发。

## 🎯 培训目标

- 了解项目架构和代码规范
- 掌握开发环境搭建
- 熟悉 Git 工作流程
- 了解代码审查流程

## 📅 培训计划

### 第 1 天：项目概览

#### 上午
1. **项目介绍** (1 小时)
   - 项目背景和目标
   - 技术栈介绍
   - 团队结构

2. **架构概览** (2 小时)
   - DDD 架构设计
   - 前后端分离
   - 核心模块介绍

#### 下午
1. **开发环境搭建** (2 小时)
   - 安装开发工具
   - 克隆仓库
   - 配置环境

2. **运行项目** (1 小时)
   - 启动后端服务
   - 启动前端服务
   - 验证环境

### 第 2 天：开发规范

#### 上午
1. **代码规范** (2 小时)
   - Java 编码规范
   - TypeScript 编码规范
   - 代码审查标准

2. **Git 工作流程** (2 小时)
   - 分支管理
   - 提交规范
   - PR 流程

#### 下午
1. **测试规范** (2 小时)
   - 单元测试
   - 集成测试
   - 测试覆盖率

2. **安全规范** (1 小时)
   - 安全编码
   - 敏感信息处理
   - 漏洞修复

### 第 3 天：实战演练

#### 上午
1. **功能开发演练** (3 小时)
   - 选择一个简单任务
   - 完成开发
   - 提交 PR

#### 下午
1. **代码审查** (2 小时)
   - 审查他人代码
   - 接受代码审查
   - 学习反馈

2. **问题排查** (2 小时)
   - 日志分析
   - 调试技巧
   - 常见问题

## 📊 培训效果评估

### 评估方式
1. **知识测试**: 培训结束后进行
2. **代码审查**: 观察代码质量
3. **任务完成**: 跟踪任务完成情况

### 评估标准
- **优秀**: 独立完成复杂任务
- **良好**: 在指导下完成任务
- **及格**: 需要较多帮助
- **不及格**: 需要重新培训
