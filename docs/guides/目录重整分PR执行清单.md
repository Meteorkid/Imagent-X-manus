# 目录重整分 PR 执行清单

## PR-1（P0）：仓库噪音与敏感信息治理
- 目标：先处理风险最高且最易回滚的项。
- 范围：
  - 完善 `.gitignore`（重点 `.next`）。
  - 敏感信息文档模板化与替换策略。
- 验收：
  - `git status` 无构建产物噪音。
  - 文档中不出现真实密钥。

## PR-2（P1）：文档入口与分类收口
- 目标：将根目录过程文档迁移到 `docs` 分类目录。
- 范围：
  - 根 README 保留入口与导航。
  - 报告类放 `docs/reports`，指南类放 `docs/guides`。
- 验收：
  - 根目录文档数量显著降低。
  - README 关键链接可用。

## PR-3（P1）：脚本与文档分离
- 目标：`docs` 仅放说明，脚本统一进入 `scripts`。
- 范围：
  - 迁移 `docs` 下 `.sh` 文件到 `scripts` 子目录。
  - 文档保留命令示例和参数说明。
- 验收：
  - 脚本路径清晰统一。
  - 文档不再承载可执行脚本文件。

## PR-4（P2）：部署配置入口收敛
- 目标：统一 `config/docker` 与根目录 compose 入口策略。
- 范围：
  - 明确一个主入口脚本和 compose 目录约定。
  - 修复 README 与脚本中的路径漂移。
- 验收：
  - 一条命令可按文档成功启动。

## PR-5（P3）：高影响目录收敛
- 目标：处理 `frontend` / `frontend-current` 与重复静态资源。
- 范围：
  - 确定主线目录并归档非主线目录。
  - 统一重复资源目录（如 `offline-dino`）。
- 验收：
  - 前端唯一主目录清晰。
  - 资源引用无断链。
