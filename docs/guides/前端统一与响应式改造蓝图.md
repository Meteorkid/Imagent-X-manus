# 前端统一与响应式改造蓝图（全页面）

## P0（当前实施）
1. Provider 树统一
- 根布局保留全局 `ThemeProvider + Providers`。
- `(main)`、`(auth)` 移除重复全局 Provider，仅保留业务级 Provider。

2. 断点单一来源
- 建立共享断点常量，JS Hook 与 Tailwind 对齐。
- 移除重复 `use-mobile` 实现，只保留一个入口。

3. 动态 Tailwind 类修正
- 将 `grid-cols-${}`、`gap-${}` 改为静态映射表，保证构建可收集。

4. 基础文件一致性
- 修复 `components.json` 的全局样式路径。

## P1（下一阶段）
1. 页面骨架统一
- 抽象 `MainShell` / `AdminShell`。
- 统一高度策略为 `min-h-svh` 与稳定滚动容器。

2. 视觉语义统一
- 逐页替换硬编码 `gray/blue` 为语义 token 类。
- 统一卡片、按钮、空态、表格与弹窗风格。

## P2（持续治理）
1. 页面瘦身
- 页面仅保留编排逻辑，数据请求与状态迁移到 hooks/services。
2. 组件收敛
- 清理重复 Dialog/Hook，实现单一可信组件源。
3. 回归自动化
- 建立断点 UI smoke 清单与关键路径截图比对。
