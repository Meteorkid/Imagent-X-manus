# 实施前检查单与验收标准

## 实施前检查单
- 已完成全项目审查与风险台账，并确认 P0 改造范围。
- 当前工作区存在大量历史变更，实施时仅修改目标文件，避免误触其他改动。

- 改动按小步提交，单次变更类型单一。

## P0 验收标准
1. Provider 去重
- `(main)` 与 `(auth)` 不再重复包裹全局 Provider。
- 全站主题、账户状态与消息提示行为正常。

2. 响应式断点统一
- JS 断点常量存在单一来源。
- `useIsMobile` 只保留一个实现入口。

3. Tailwind 动态类修正
- 无 `grid-cols-${}`、`gap-${}`、`text-${}` 这类运行时拼接类。
- 关键组件在构建后样式不丢失。

4. 配置一致性
- `components.json` 引用的全局 CSS 路径正确。

## 回归测试清单
- 页面：登录、explore、tools、knowledge、studio、workspace、admin。
- 分辨率：`375x812`、`768x1024`、`1366x768`、`1920x1080`。
- 主题：浅色/深色各执行一次关键路径。
- 交互：顶部导航、侧边栏、弹窗、表单、列表滚动。
