## 📝 教程脚本

### 安装部署教程脚本

```markdown
# 安装部署教程

## 开场白
大家好，欢迎来到 ImagentX 安装部署教程。在这个教程中，我将向您展示如何快速安装和部署 ImagentX 平台。

## 第一部分：环境准备
首先，我们需要准备以下环境：
- Docker 20.10+
- Docker Compose 2.0+
- 至少 4GB 内存

## 第二部分：下载 ImagentX
使用 git 克隆仓库：
git clone https://github.com/Meteorkid/Imagent-X-manus.git

## 第三部分：配置环境变量
复制环境变量模板并配置：
cp .env.example .env

## 第四部分：启动服务
使用 Docker Compose 启动所有服务：
docker-compose up -d

## 第五部分：验证安装
打开浏览器访问 http://localhost:3000

## 结束语
恭喜您成功安装了 ImagentX！接下来，您可以继续观看快速入门教程。
```
